# Documentació

Tota la documentació del lliurament va en aquesta carpeta:

- **`memoria.md`**: la memòria, en Markdown (vegeu al README del projecte què ha de contenir: optimitzacions, heurística i resum de resultats);
- **`img/`**: les imatges de taules i gràfics que enllaça la memòria, amb rutes relatives (`![Títol](img/fitxer.png)`);
- **`registre.md`**: el registre històric de proves, amb referències als tags de GitHub (obligatori).
